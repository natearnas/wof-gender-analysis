# Wheel of Fortune Gender Analysis

This was a fun exploratory data-science project that grew into a more rigorous analysis pipeline.

The project tests whether Wheel of Fortune winnings patterns differ by gender, with a longitudinal focus on the plastic-cap era (S38-S39) versus surrounding seasons (S36-S37, S40-S41).

## Project Context

- The original write-up was published earlier as a long-form blog post:
  - <https://arnastech.com/f/did-covid-break-the-wheel-a-6-season-forensic-analysis-of-gender#8de304a8-9dee-47d4-b205-42cfa92ee11f>
- This repository is the public, reproducible release of that work.
- The intent is transparency: code, core data artifacts, and outputs are all available for inspection.

## At A Glance

- Cross-sectional analysis shows a male-female average winnings gap in the pooled sample.
- Longitudinal DiD analysis finds that this gap narrows substantially during the plastic-cap era.
- The repo includes reproducible datasets and result summaries so you can audit the outputs directly.

## What This Repo Does

- Collects and stores season-level episode data (`main.py`).
- Normalizes episode data to player-level records (`01_data_validation.py`).
- Runs cross-sectional hypothesis tests on winnings (`02_hypothesis_testing.py`).
- Runs longitudinal difference-in-differences analysis (`03_longitudinal_analysis.py`).
- Includes multi-source collection/coverage scripts for season 39 (`main_multi_source.py`, `analyze_multi_source.py`).

## Data Availability

To support reproducibility, this repo includes the core datasets used in analysis:

- Season-level episode extracts as CSV files in `data/processed/`  
  (for example, `S36_raw.csv` through `S41_raw.csv`)
- Combined longitudinal dataset: `data/processed/longitudinal_data_raw.csv`
- Player-level normalized dataset: `data/processed/player_level_data.csv`
- Summary result files:
  - `data/processed/hypothesis_testing_results.txt`
  - `data/processed/longitudinal_did_results.txt`

Note: some files are episode-level raw extracts, but they are currently stored in `data/processed/` for project convenience.

## Project Structure

- `src/`: scraper and utility modules
- `data/raw/`: raw input artifacts (mostly untracked except folder placeholder)
- `data/processed/`: analysis datasets and tracked outputs
- `01_data_validation.py`: player-level normalization + validation plots
- `02_hypothesis_testing.py`: Mann-Whitney/bootstrap-focused cross-sectional analysis
- `03_longitudinal_analysis.py`: DiD and robustness checks across seasons
- `main.py`: longitudinal scraping pipeline

## Setup

1. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

## Typical Analysis Run (No Re-scrape)

If you already have the CSV baselines in `data/processed`, run:

```powershell
python 01_data_validation.py
python 02_hypothesis_testing.py
python 03_longitudinal_analysis.py
```

## Full Data Collection Run

To rebuild the longitudinal dataset from source pages:

```powershell
python main.py
```

This writes season checkpoints (`S36_raw.csv` ... `S41_raw.csv`) plus:

- `data/processed/longitudinal_data_raw.csv`

## Methodology Notes And Limitations

- Gender labels include `Unknown`; most inferential tests filter to confirmed `M` and `F`.
- Name-based gender classification is heuristic and should be treated as a limitation.
- Web-scraped sources can change over time; use committed processed baselines for reproducibility checks.
- This is an observational analysis and should not be interpreted as a causal claim.
